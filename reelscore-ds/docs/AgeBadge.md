# AgeBadge

A small gold tag showing the content's age rating (7+, 13+, 18+).

**Consumer provides:** `rating` (the text).

- Place it above the hero meta row or beside a title on detail pages; never on poster cards.
- `on-gold` on `gold-deep`, `radius-xs`. Read aloud as "Rated 13+".
